# SceneForge

将单张或多张风景照片重建为**可追溯、可编辑、可分级发布**的 3D 场景工程。

- 整个风景分层重建：地形、建筑、植被、水面、天空与光照。
- 支持多图几何重建，也支持单图结合地理数据与参考资料补全。
- 高精度 Blender 母版与 three.js 发布档分离，按需生成多级 LOD。
- 所有事实、外部数据、假设与人工确认统一记录在 `scene.json`。
